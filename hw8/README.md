# 과제 08: 최소 비용 신장 트리 알고리즘 비교

## 실행 방법

`hw8.exe`를 실행한다. 인자를 생략하면 현재 시각을 난수 시드로 사용한다. 숫자 인자를 주면 같은 환경에서 그래프를 재현할 수 있다. 다른 C 라이브러리의 `rand()` 구현에서는 같은 시드여도 그래프가 달라질 수 있고 같은 그래프여도 실행시간은 매번 달라진다.

## 그래프 생성과 표현

정점 번호는 0~49이고 가중치는 1~1000의 양의 정수이다. 정점 순서를 무작위로 섞은 후 각 정점을 앞서 연결된 정점 중 하나에 연결하여 49개 간선의 트리를 먼저 만든다. 그 뒤 아직 없는 간선 후보를 무작위로 선택해 간선 수를 각각 100개와 600개로 맞춘다. 후보는 `u < v`인 쌍만 사용하므로 자기 간선과 중복 간선이 없다.

이 방법은 연결성을 보장하며 생성 후 BFS로 전체 50개 정점에 도달하는지도 다시 확인한다. 연결 그래프 전체에서 균등 표본을 뽑는 방식은 아니지만 임의의 가중치 연결 그래프를 생성한다는 과제 조건을 만족한다.

각 가중치 행렬에서 동일한 가중치를 가진 연결 리스트를 구성한다. 무방향 간선 하나는 리스트 노드 두 개로 표현한다. Kruskal은 이 리스트만 입력으로 사용하고 행렬은 Prim의 입력으로 사용한다. 희소의 Case 1·3과 밀집의 Case 2·4는 각각 같은 정점·간선·가중치를 사용한다.

## 알고리즘 구현

### 인접 리스트 + Kruskal

리스트를 순회하면서 `u < v`인 간선만 추출하여 E개 간선 배열을 만든다. 제자리 힙 정렬로 가중치 오름차순 정렬한 뒤 Union-Find로 서로 다른 집합을 연결하는 간선을 선택한다. 경로 압축과 rank에 따른 합치기를 사용한다. 선택한 간선이 49개가 되면 종료한다.

간선 추출, 정렬, Union-Find 초기화와 선택 과정 모두 구현에 포함된다. 정렬은 O(E log E)이며 별도 정렬용 배열이나 재귀 스택이 필요하지 않다.

### 인접 행렬 + Prim

시작 정점은 0으로 정한다. 방문 여부, 최소 연결 비용, 부모 정점 배열을 관리한다. 아직 선택하지 않은 정점 중 최소 비용 정점을 선형 탐색으로 선택하고 행렬의 해당 행을 확인하여 다른 정점의 최소 비용을 갱신한다. 정점 50개를 모두 선택하며 루트를 제외한 49개 연결을 MST에 저장한다.

매 단계에서 정점 선택과 행 확인을 수행하므로 시간 복잡도는 O(V²)이다. 간선 수가 달라도 행렬과 정점 배열을 훑는 기본 반복 횟수는 같다.

## 메모리와 실행시간 측정

### 메모리

그래프 표현, 알고리즘의 주요 보조 자료구조, MST 결과 저장 공간의 합을 측정한다. 난수 생성용 간선 후보 배열, 검증용 배열, 타이머·출력 관리 공간, 다른 비교 사례의 그래프는 각 사례의 메모리에 넣지 않는다. `sizeof`에는 구조체 패딩이 포함되며 메모리 할당기의 내부 관리 공간과 소수의 스칼라 지역 변수·함수 호출 프레임은 제외한다. 따라서 프로세스 전체 메모리가 아니라 주요 자료구조의 공간 합이다.

이번 64비트 실행 환경에서의 크기는 다음과 같다.

- 리스트 표현: `sizeof(List) + 2E × sizeof(Link) = 408 + 32E`바이트
- 행렬 표현: `sizeof(Matrix) = 10004`바이트
- Kruskal 보조 공간: 간선 배열 `12E` + Union-Find `400` + MST 결과 `596`바이트
- Prim 보조 공간: 방문·최소 비용·부모 배열 `600` + MST 결과 `596`바이트

Kruskal 간선 배열은 실제 간선 수 E만큼 동적 할당한다. 정렬은 그 배열 안에서 수행한다. 두 알고리즘 모두 MST 결과 공간을 포함하므로 같은 기준으로 비교한다.

### 실행시간

네 경우 모두 같은 최적화 옵션과 타이머를 사용한다. Windows에서는 `QueryPerformanceCounter`로 경과시간을 측정하고 ms로 출력한다. 비Windows 빌드에서는 `clock()`의 CPU 시간을 사용한다. 아래 결과는 Windows의 경과시간이다.

그래프 생성과 리스트 변환은 측정 전에 완료한다. 측정 구간에는 Kruskal의 간선 추출·할당·정렬·Union-Find 처리·임시 배열 해제와 Prim의 보조 배열 초기화·정점 선택·비용 갱신이 포함된다. 결과 출력, 연결성 검사 및 MST 검증은 측정 구간 밖에 둔다.

50개 정점의 실행은 매우 짧으므로 같은 그래프에서 매번 처음부터 MST를 계산하는 1000회 실행을 연속 측정하고 총시간을 1000으로 나눈 평균을 출력한다. 결과를 재사용하지 않으며 정렬도 매번 다시 수행한다. 두 알고리즘은 원본 그래프를 변경하지 않는다. 반복 호출의 작은 제어 비용은 포함된다.

## 실측 결과 분석

### 희소 그래프

정점 50개의 최대 무방향 간선 수는 1225개이다. 희소 그래프의 밀도는 `100/1225 ≈ 8.16%`이다. 리스트는 존재하는 간선만 저장하므로 그래프 공간이 3,608바이트로 빈 위치까지 저장하는 행렬 10,004바이트보다 작았다. 간선 정렬 배열과 Union-Find를 포함해도 Kruskal의 총메모리는 5,804바이트로 Prim의 11,200바이트보다 5,396바이트 적었다.

시간도 Kruskal 0.002673ms, Prim 0.005365ms로 이번 실험에서는 Kruskal이 약 2배 빨랐다. 정렬할 간선이 100개로 적은 반면 Prim은 간선이 없는 위치를 포함해 50개 정점의 행렬을 계속 확인하기 때문이다. 따라서 이 희소 사례에서는 리스트 + Kruskal이 메모리와 시간 모두 유리하였다.

### 밀집 그래프

밀도는 `600/1225 ≈ 48.98%`이다. 무방향 리스트 노드가 1200개로 증가하여 그래프 공간이 19,608바이트가 되었고 정렬용 간선 배열도 7,200바이트로 커졌다. Kruskal 총메모리 27,804바이트는 Prim 11,200바이트보다 16,604바이트 많았다. 리스트는 각 인접 항목에 포인터를 저장하고 Kruskal은 간선 배열도 추가로 유지하기 때문이다.

Kruskal은 0.017140ms로 희소 때보다 약 6.41배 오래 걸렸다. 간선 수가 6배로 늘면서 리스트에서 추출할 항목과 정렬할 간선이 모두 증가하였다. MST에 선택할 간선 수는 여전히 49개지만 정렬은 600개 전체에 대해 먼저 수행해야 한다.

Prim은 희소 0.005365ms에서 밀집 0.005979ms로 증가했지만 차이는 상대적으로 작았다. 정점 수가 동일하여 O(V²)의 기본 탐색 범위는 같고 연결된 간선이 많아지면서 조건 통과와 비용 갱신 횟수 등이 달라졌기 때문이다. 이번 밀집 사례에서는 Prim이 Kruskal보다 약 2.87배 빨랐으며 메모리도 적었다.

### 선택 기준과 한계

간선이 적으면 리스트의 O(V+E) 공간과 Kruskal의 간선 중심 처리가 유리할 수 있다. 간선이 많으면 리스트의 노드·포인터 및 간선 정렬 배열 비용이 커지므로 O(V²) 공간을 사용하는 행렬과 O(V²) Prim이 상대적으로 유리해진다. 이번 측정에서 이 차이가 실제 메모리와 시간에 나타났다.

이번 과제는 표현과 알고리즘을 함께 바꾸므로 시간 차이를 표현 방법 하나만의 효과로 분리할 수 없다. 힙 기반 Prim 등 다른 구현과 비교한 결과도 아니다. 또 각 밀도에서 하나의 그래프를 반복 실행한 평균이므로 여러 무작위 그래프의 평균 성능은 아니다. 반복 실행으로 캐시와 메모리 할당기 상태가 안정되는 효과도 있으며 짧은 실행시간은 시스템 부하에 따라 변한다. 따라서 기록된 시간은 이번 환경과 구현의 실험값으로 해석한다.

## 검증

프로그램과 테스트를 경고 없이 컴파일하였다. 제출 프로그램은 MST 간선이 원래 그래프에 존재하는지, 가중치가 맞는지, 간선 수가 49인지, 사이클 없이 전체 정점을 연결하는지, 합산 비용이 맞는지 검사한다.

추가로 원래 그래프의 모든 간선에 대해 MST 안에서 두 끝점을 잇는 경로의 최대 가중치가 그 간선의 가중치보다 크지 않은지 검사한다. 이 사이클 최적성 조건으로 더 작은 비용의 간선 교환이 불가능한지 확인하므로 두 알고리즘의 비용이 우연히 같다는 사실만으로 정답을 판단하지 않는다. 이 검증은 실행시간과 측정 메모리에 포함하지 않는다.

별도 테스트에서는 시드 0~9의 희소·밀집 그래프 총 20개에 대해 연결성, 정점·간선 수, 가중치 범위, 두 표현의 일치, 두 MST의 최적성과 비용 일치를 확인하였다. 모든 가중치가 1인 경우 MST 비용 49, 비연결 그래프의 실패 처리, 변조된 비용의 거부도 확인하였다.
