# 과제 04: 반복적 이진트리 순회

## 실행 방법과 입력

각 노드는 영문 대문자 한 글자이다. 단말 노드는 `A`처럼 괄호 없이 표현한다. 양쪽 자식은 `A(B,C)`, 오른쪽 자식만 있으면 `A(,C)`로 표현한다. 왼쪽 자식만 있는 `A(B)`와 `A(B,)`를 모두 지원하며 입력에 포함된 공백은 제거한다. 한 줄은 줄바꿈을 제외하고 최대 4094자로 제한한다.

입력이 비어 있거나 대문자가 아닌 데이터, 짝이 맞지 않는 괄호, 잘못된 쉼표, 세 번째 자식, 입력 뒤의 불필요한 문자 등이 있으면 오류를 출력한다. 단말 노드에 빈 괄호를 붙인 `A()`와 `A(,)`도 잘못된 표기로 처리한다. 오류가 있으면 구성 중이던 노드들을 해제하고 순회하지 않은 채 종료한다.

## 연결 자료구조와 반복적 구현

`Node`는 데이터 `data`와 두 포인터 `left`, `right`를 가진다. 각 노드는 `malloc`으로 생성하고 실제 트리의 연결 관계는 자식 포인터로 저장한다. 배열은 탐색 과정에서 사용할 보조 스택이며 트리 자체를 저장하는 배열 표현이 아니다.

프로그램 전체에 재귀 호출을 사용하지 않았다. 입력 해석은 부모 노드와 처리 상태를 스택에 보관한다. 구조 출력은 노드와 깊이, 메모리 해제는 아직 처리하지 않은 자식 포인터를 스택에 보관한다. 정상 종료와 입력 오류 모두 반복적인 해제 함수를 사용한다.

스택 용량은 입력 버퍼와 같은 `MAX_INPUT`이다. 한 노드마다 입력 문자가 최소 하나 필요하므로 입력 길이를 제한하면 생성 가능한 노드 수와 필요한 스택 칸 수도 이 용량을 넘지 않는다.

### 전위 순회: preorder(tree)

루트를 스택에 넣고 시작한다. 스택에서 꺼낸 노드를 방문한 다음 오른쪽 자식과 왼쪽 자식 순서로 넣는다. 스택은 나중에 넣은 항목을 먼저 꺼내므로 실제 방문 순서는 **Root → Left → Right**가 된다.

### 중위 순회: inorder(tree)

현재 노드에서 왼쪽으로 내려가면서 노드들을 스택에 넣는다. 더 내려갈 수 없으면 스택에서 노드를 꺼내 방문한 뒤 그 노드의 오른쪽 자식으로 이동한다. 이 과정을 반복하여 **Left → Root → Right** 순서로 방문한다.

### 후위 순회: postorder(tree)

왼쪽으로 내려가며 노드들을 스택에 넣는다. 왼쪽 처리가 끝나면 스택 맨 위 노드의 오른쪽 자식이 아직 처리되지 않았는지 확인한다. 처리하지 않은 오른쪽 자식이 있으면 먼저 이동하고 없거나 이미 처리했다면 현재 노드를 방문하고 스택에서 꺼낸다.

`last_visited`에 마지막으로 방문한 노드의 포인터를 저장하여 오른쪽 서브트리의 처리 완료 여부를 판단한다. 문자 값이 아닌 포인터를 비교하기 때문에 데이터가 같은 노드들도 구분한다. 방문 순서는 **Left → Right → Root**이다.

노드 수가 n일 때 각 순회는 모든 노드를 한 번씩 방문하므로 시간 복잡도는 O(n)이다. 스택의 실제 사용량은 트리 높이에 비례하지만 현재 구현은 입력 상한에 맞춘 고정 크기 배열을 미리 확보한다.

## 11개 노드 시험

왼쪽과 오른쪽 서브트리를 모두 포함하고 한쪽 자식만 있는 노드도 포함하도록 다음 트리를 사용하였다. 총 노드는 A부터 K까지 11개이다.

```text
A(B(D(H,I),E(,J)),C(F(K,),G))
```

실제 프로그램 출력은 다음과 같다.

```text
입력한 트리: A(B(D(H,I),E(,J)),C(F(K,),G))

[트리 구조]
A
+---B
    +---D
        +---H
        +---I
    +---E
        +---J
+---C
    +---F
        +---K
    +---G

Preorder  : A B D H I E J C F K G
Inorder   : H D I B E J A K F C G
Postorder : H I D J E B K F G C A
```

전위 순회에서는 루트 A가 맨 앞에 나온다. 중위 순회에서는 왼쪽 서브트리의 6개 노드를 방문한 후 A가 나온다. 후위 순회에서는 두 서브트리를 모두 방문한 후 A가 맨 마지막에 나온다. B와 C의 서브트리에도 같은 방문 규칙이 적용된다.

## 검증 결과

Windows x64에서 visual studio 2026을 통해 경고와 오류 없이 컴파일되었으며 다음 검사를 통과하였다.

- 단일 노드, 좌우 자식, 과제의 6개 노드 예제, 위 11개 노드 예제, 편향 트리, 공백과 중복 데이터 등을 포함한 정상 입력 10종의 세 순회 결과를 예상값과 비교하였다.
- 빈 입력, 괄호·쉼표 오류, 세 번째 자식, 잘못된 데이터와 길이 초과 등 잘못된 입력 23종이 오류로 종료되고 순회 결과를 출력하지 않는지 확인하였다.
- 1000개 노드가 왼쪽으로 이어진 깊은 트리에서 입력 해석, 구조 출력, 세 순회와 메모리 해제까지 정상 종료하는지 확인하였다. 각 순회에서 1000개 데이터가 출력되었다.
