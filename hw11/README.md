# 과제 11: 삽입 정렬과 쉘 정렬의 성능 비교

## 실행 방법

`hw11.c` 하나만 컴파일한다. 시드를 생략하면 현재 시각을 사용한다. 동일 실행 환경과 시드에서는 재현할 수 있지만 C 라이브러리의 `rand()` 구현이 다르면 난수와 측정값이 달라질 수 있다.

## 실험 방법과 비교 횟수의 기준

데이터 크기는 1,000, 2,000, 4,000, 8,000, 16,000, 20,000이다. 크기마다 0~1,000,000의 무작위 정수를 새로 생성하며 중복을 허용한다. 각 크기에서 세 정렬은 동일한 원본의 복사본을 사용한다. 크기별로 한 번씩 측정한다.

삽입 정렬은 간격 1의 삽입 과정으로 구현했다. 쉘 정렬은 각 간격에 대해 간격 삽입 정렬을 수행한다. 공통 함수 `gap_insertion`은 `a[j-gap] <= value`를 실제 수행하기 직전에 비교 횟수를 1 증가시킨다. 이동 여부와 관계없이 비교를 세므로 이미 올바른 위치임을 확인하고 멈추는 비교도 포함한다. `j >= gap` 등의 인덱스 검사, 간격 생성, 난수 생성, 배열 복사, 결과 검증은 제외한다.

각 결과를 독립적으로 만든 기준 정렬 결과와 원소별로 대조한다. 따라서 오름차순뿐 아니라 중복을 포함한 값의 누락·변경도 확인한다. 라이브러리 `qsort`는 이 검증 기준을 만드는 용도로만 사용하고 세 실험 알고리즘은 직접 구현했다.

## 간격 수열

- 기본 간격: `n/2`부터 정수 나눗셈으로 계속 절반으로 줄인다. 홀수는 버림 처리되며 마지막은 1이다.
- Knuth 간격: 1부터 `3h+1`을 생성해 n보다 작은 가장 큰 간격을 선택하고 `(h-1)/3`으로 역순 적용한다. 일반적인 다른 시작 조건인 `n/3`을 기준으로 제한하지 않는다.

예를 들어 n=20,000의 실제 적용 순서는 다음과 같다.

```text
기본: 10000, 5000, 2500, 1250, 625, 312, 156, 78, 39, 19, 9, 4, 2, 1
Knuth: 9841, 3280, 1093, 364, 121, 40, 13, 4, 1
```

두 방식 모두 간격 1로 끝나므로 최종 배열 전체가 오름차순으로 정렬된다. 프로그램은 모든 크기의 실제 간격을 함께 출력한다.

### 데이터 크기에 따른 변화

삽입 정렬은 크기가 두 배가 될 때 비교 횟수가 대체로 네 배로 증가했다. 예를 들어 4,000→8,000에서는 약 4.05배, 8,000→16,000에서는 약 4.01배였다. 무작위 입력에서는 새 원소를 삽입할 때 앞쪽의 많은 값을 확인하고 이동해야 한다. 따라서 평균적인 이차 증가 경향 O(n²)이 나타난다. 실제 값도 대략 n²/4에 가까웠다. 마지막 16,000→20,000은 크기가 1.25배이므로 두 배 증가와 구분해야 하며 비교는 약 1.58배 증가했다.

쉘 정렬의 증가 폭은 이번 입력에서 더 작았다. 기본 간격은 4,000→8,000에서 약 2.38배, 8,000→16,000에서 약 2.48배였고 Knuth는 각각 약 2.48배와 2.26배였다. 이 유한한 실험의 비율만으로 쉘 정렬의 보편적인 복잡도 지수를 확정할 수는 없지만 측정 범위에서는 삽입 정렬보다 비교 횟수 증가가 훨씬 완만했다.

### 삽입 정렬과 쉘 정렬의 차이

20,000개에서 삽입 정렬은 101,102,435회, 기본 쉘은 599,231회, Knuth 쉘은 561,299회 비교했다. 삽입 정렬의 비교 횟수는 각각 약 168.7배, 180.1배였다. 이는 비교 횟수의 비율이다.

삽입 정렬은 처음부터 간격 1로 처리하므로 멀리 떨어진 작은 원소를 앞쪽으로 보내는 데 많은 값 비교가 필요하다. 쉘 정렬은 큰 간격에서 떨어진 원소들을 먼저 정리해 원소가 최종 위치에 가까워지도록 한다. 이후 작은 간격의 삽입 과정은 앞선 단계에서 정리된 상태를 활용한다. 여러 간격을 처리하는 추가 비교가 있어도 무작위 입력에서는 마지막 간격 1에서 필요한 작업이 크게 감소해 전체 비교가 적었다.

### 기본 간격과 Knuth 수열의 차이

이번 여섯 입력에서는 Knuth가 모두 적게 비교했다. 그러나 절감 폭은 일정하지 않았다. 2,000개에서는 35,003→34,448로 약 1.59% 감소한 반면 16,000개에서는 498,254→411,372로 약 17.44% 감소했다. 20,000개에서는 37,932회, 약 6.33% 감소했다.

간격은 같은 부분 수열에 묶이는 원소들과 한 번에 이동할 수 있는 거리를 결정한다. 기본 수열에서 초반 간격이 계속 배수 관계에 있으면 비슷한 위치 그룹을 반복해서 정리할 수 있다. Knuth의 `3h+1` 수열은 단계가 바뀔 때 원소들의 그룹 구성을 다르게 만들고 큰 간격에서의 정리를 다음 단계로 전달한다. 다만 이것만으로 모든 입력에서 Knuth가 우세하다고 보장하지는 않는다.

20,000개에서는 기본 방식이 14단계, Knuth가 9단계였다. 단계 수가 적으면 각 단계의 기본 비교 부담이 줄 수 있지만 간격이 너무 크면 일부 원소만 비교하며 다음 단계에 많은 작업을 남길 수도 있다. 즉 성능은 단계 수뿐 아니라 각 단계에서 남은 무질서와 간격 사이의 관계에 달려 있다. 이번에는 그 합계가 Knuth에서 작았으며 크기별 절감률의 차이도 입력과 수열의 조합이 중요함을 보여 준다.

각 크기당 무작위 입력 한 개의 결과이므로 모든 입력 분포에서 동일한 차이를 단정할 수는 없다. 특히 이미 정렬된 입력은 삽입 정렬이 n-1번 비교로 끝나는 반면 쉘 정렬은 여러 간격을 처리하므로 이번 무작위 실험의 우열을 그대로 적용해서는 안 된다.
